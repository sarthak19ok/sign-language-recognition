Chapter 1

Introduction

1.1 Background
Sign languages communicate through coordinated hand shape and motion, body posture,

and facial or head cues. Recognizing an isolated sign from a short video is a multi-class

classication task: a clip is assigned one word-level gloss. It diers from continuous sign-

language translation, which must also locate sign boundaries and model sentence-level

structure.

This project explores a lightweight recognition pipeline based on pose landmarks rather

than raw video pixels.   Landmark features reduce the visual input to body and hand

coordinates and make it possible to compare classical machine-learning methods with

temporal neural networks.




1.2 Problem statement
The objective is to classify each WLASL-100 video instance into one of 100 gloss classes

while evaluating on signers absent from model training. The main methodological chal-

lenge is to build a reproducible pipeline despite incomplete video availability, missing

landmarks, and substantial signer variation.




1.3 Objectives
1. Audit the WLASL-100 metadata and establish a reproducible, signer-independent

   dataset split.


2. Obtain available clips and extract pose and hand landmarks once for downstream

   experiments.


3. Quantify clip, signer, class, and landmark coverage before modelling.


                                             1
4. Compare coordinate, angle, velocity, and temporal aggregation choices.


5. Tune classical and recurrent classiers without signer leakage and report held-out test

   performance.




1.4 Questions guiding the experiments
We organized the work around three practical questions. First, how much information

about an isolated gloss can be recovered from body and hand landmarks alone? Second,

which representation and model family performs best when signers in evaluation were not

seen during training?   Third, how much does a random clip split change the apparent

result when signers overlap?   These questions keep the analysis focused on the choices

we could measure with the data available. They also shaped the experiments: channel

ablations address the rst question, grouped cross-validation and the frozen test split

address the second, and the random-split diagnostic illustrates the third.




1.5 Why signer independence matters
An evaluation split should match the kind of generalization we want to measure. If the

same people appear in both training and test data, a model can benet from recurring

recording conditions or signer-specic movement patterns. This is especially important

for a relatively small dataset, where a model might learn the style of a few frequent signers

rather than features that transfer to people it has not seen.     We therefore treat signer

identity as a grouping variable throughout the main evaluation, even though it is not an

input feature for the classiers.




1.6 Scope
We focus on recognizing one pre-segmented sign per clip from the WLASL-100 subset. We

use MediaPipe Holistic landmarks rather than training directly on video pixels. Continu-

ous signing, sentence translation, and a live-camera application are outside this project.

Related Work

2.1 Word-level sign recognition
Word-level sign recognition assigns a gloss to a pre-segmented sign video. The segmen-

tation is assumed to be given: each example already contains one intended sign, so the

model does not need to detect where a sign begins or ends. This makes the task narrower

than continuous sign recognition, but still challenging because the same gloss can look

dierent across people and recordings.

WLASL provides word-level ASL clips and signer metadata for benchmarking recognition

across a large set of glosses. The dataset paper evaluates video-based recognition methods;

we use the WLASL-100 subset for a landmark-based pipeline and focus on a signer-

independent comparison [1]. The subset gives us a xed vocabulary of 100 glosses and

enough signer variation to make the split strategy a central part of the experiment.




2.2 Pose-based representations
Pose estimation represents a person using a set of body joints. For sign recognition, hands

carry detailed information about conguration and movement; upper-body landmarks

add context and provide a reference for where the hands are positioned.       A landmark

representation can be smaller and easier to inspect than raw pixels, but it depends on the

pose estimator returning stable points. Missed hands or inconsistent coordinates become

missing or noisy model inputs.

MediaPipe Holistic estimates pose and hand landmarks in a unied pipeline [2]. In this

project, each frame contains 33 pose points and 21 points for each hand, with three

coordinates per point, for 225 values per frame. We keep this representation rather than

cropping each hand to an image because the project goal is to compare a shared set of

geometric features across classical and temporal models.




                                            3
2.3 Classical and temporal classiers
We use classical classiers as strong, relatively quick baselines for compact feature vec-

tors. Logistic regression provides a linear decision boundary and a useful reference point.

kNN assigns a class based on nearby training examples, so it depends on scaling and on

the selected distance neighbourhood. An RBF SVM can describe nonlinear boundaries

through a kernel. Random Forest and Extra Trees average many decision trees, while XG-

Boost builds trees sequentially to correct errors from previous trees. These models make

dierent assumptions about the geometry of the input, which is why one representation

need not suit all of them equally well.

LSTM and GRU networks instead read a sequence one frame at a time and maintain

a hidden state. Both are gated recurrent models designed to retain information across

a sequence.   We use bidirectional versions so that the representation of a frame can

incorporate information from both earlier and later frames in the clip.     These models

have more trainable parameters than the xed-vector baselines and can overt when the

number of clips per class is small.   The comparison is therefore useful even when the

recurrent models do not lead the nal scores.

The scikit-learn tools provide the classical pipelines and grouped cross-validation used

here [3]. XGBoost supplies the gradient-boosted tree model, and PyTorch supplies the

recurrent networks [5, 4]. In every case, a model's reported score depends on the repre-

sentation, the tting procedure, and the split; comparing algorithm names alone would

not be meaningful.




2.4 Evaluation and signer leakage
Recordings from the same signer can share appearance, camera placement, clothing, and

signing style. If clips from one signer appear in both training and test sets, a model may

exploit signer-specic cues.   We therefore keep signers disjoint across train, validation,

and test partitions and use signer-grouped folds during model selection.

3.4 Preprocessing and features
We interpolate gaps of up to three frames and leave longer gaps missing. Coordinates

are centered on the shoulders and scaled by shoulder width, then resampled to a xed



                                            7
sequence length.     The saved feature bundle contains normalized coordinates, frame-to-

frame velocity, and joint angles. For the classical comparison, we summarize 64 frames

in two temporal bins using both hands and their angles. For LSTM and GRU, we use

32-frame hand-and-angle sequences and provide a mask that marks missing values.

For a frame with shoulder locations pL and pR , we dene the shoulder centre as c        =
(pL +pR )/2 and the scale as s = ∥pL −pR ∥2 . A nite landmark coordinate p is transformed
to (p − c)/s. This reduces the eect of image translation and signer distance from the

camera, while preserving a relative position with respect to the upper body. If shoulder

width is missing or too close to zero, it is treated as missing rather than used as an

unstable scale.

We calculate angular features from selected triples of landmarks. Given joint locations

a, b, c, the angle at b is                                         
                                                (a − b) · (c − b)

                                               ∥a − b∥2 ∥c − b∥2
The feature set includes selected upper-body and hand-joint angles. Angles describe local

conguration while being less sensitive than raw coordinates to overall movement across

the frame. They are still aected by missed or noisy landmarks, so unavailable angles

remain missing.

Velocity is approximated by the dierence between consecutive resampled coordinates.

It captures direction and magnitude of movement between frames but can also amplify

landmark noise. This is one reason we treat velocity as an ablation rather than assuming it

will help. The feature comparison tests whether that extra dynamic information improves

signer-grouped performance.

For the 64-frame classical vector, each clip is represented across two consecutive 32-frame

windows.    Within each window, the available values are averaged feature by feature;

the two window summaries are concatenated. This preserves a coarse early-versus-late

distinction while reducing each clip to a xed vector. The sequence-length ablation uses

the same temporal pooling idea with 16, 32, or 64 frames. The nal model comparison

uses the saved 64-frame feature artifact and the same xed split.

Any imputation or scaling statistics are learned from the relevant training fold only.

The classical pipelines impute missing values, and scale inputs for models that rely on

distances or margins. Sequence-model normalization is also tted on the training portion

of each run.

This separation is important because the median, mean, and standard deviation used for

imputation and scaling contain information about the data distribution.       If they were

computed using validation or test clips, even without their labels, the evaluation would

no longer reect a strictly unseen partition. In the classical pipelines, the imputer and

scaler are part of the estimator so that each cross-validation fold ts them only on that

fold's training examples.    The recurrent workow ts its feature normalizer using the

training subset for each fold and carries the corresponding missingness mask alongside

the normalized values.

3.6 Model selection protocol
We chose classical model settings by mean macro-F1 across three signer-grouped folds of

the training partition. We then checked each selected setting on validation. For the nal

score, each model was ret using train plus validation and evaluated once on the frozen

test partition. Test results did not guide model or hyperparameter choices. We compared

LSTM and GRU input variants with the same grouped-CV approach, then evaluated the

selected hand-angle-plus-mask input on the test partition.

The three folds are formed by grouping on signer identity. This means that a fold's vali-

dation signers are absent from that fold's training data. Candidate settings are compared

on the same fold assignments so dierences are not caused by changing the validation

examples from one model to another. After selecting a setting, we t once on the original

training partition and record its validation score. For nal evaluation, the model is t

again on train plus validation, increasing the number of labelled examples used for the

nal estimator. Test labels are only used to compute the nal metrics.

For the LSTM and GRU, each input variant is evaluated over the same three outer signer-

grouped folds. An inner signer-held-out subset of the outer training portion is used to

choose the epoch with the best stopping loss. The median best epoch across the outer

folds is used when retting the selected variant. This provides an early-stopping estimate

without using the outer validation signers to choose the epoch.

3.7 Evaluation measures
We report accuracy, macro-F1, and balanced accuracy because they answer dierent

questions. Accuracy is the fraction of clips classied correctly:


                                        number of correct predictions
                           Accuracy =                                   .
                                              number of clips


For each gloss, precision measures how many clips predicted as that gloss are correct, while

recall measures how many of its true clips are found. The F1 score is the harmonic mean

of precision and recall. Macro-F1 computes F1 separately for each class and averages the

class scores, giving a rare class the same weight as a common one. Balanced accuracy

averages class recall. When support is small, both macro-F1 and balanced accuracy can

vary substantially from one clip changing category.

We use grouped-CV macro-F1 to choose classical settings, then report accuracy alongside

macro-F1 and balanced accuracy for the nal test results. This makes the selection rule

explicit and lets readers see whether overall accuracy is hiding weak performance on less

frequent glosses. The results from the test split are descriptive of this split; a single test

estimate does not provide a condence interval for new signers.




3.8 Compared models
The classical families are logistic regression, k-nearest neighbours (kNN), RBF support

vector machine (SVM), random forest, Extra Trees, and XGBoost. The temporal models

are a bidirectional LSTM and a bidirectional GRU with a 96-unit hidden state in each

direction and dropout.       Class imbalance is addressed with class weighting or sample

weighting, depending on the estimator.

The classical search grids were kept modest so that all families could be compared on the

same signer-grouped folds. Logistic regression compared C ∈ {0.1, 1, 10}. kNN compared

3, 5, and 9 neighbours with uniform or distance weighting.        The RBF SVM compared

C ∈ {10, 100, 300} and a small set of kernel-width choices.       Random Forest compared

square-root or half-feature sampling and leaf sizes of one or two. Extra Trees compared

feature fractions of 0.25, 0.5, and 0.75, leaf sizes of one or two, and balanced or unweighted

class settings. XGBoost compared depths two and three with 80 or 140 boosting rounds.

These grids are not exhaustive; they are a controlled set of practical candidates for the

available training size.

The selected settings are then xed for validation and test evaluation. The purpose of

retuning is to compare each family on its own reasonable conguration, not to make

the test score a search target. The saved scripts dene the candidate grids and training

options, and the per-model result CSVs contain the chosen values.

4.1 Feature ablations
Across the grouped training folds, using both hands with hand angles worked better than

using coordinates alone or either hand on its own.     Adding velocity reduced grouped-

CV accuracy in this experiment.     Left-hand-only accuracy was lowest; this may reect

both one-handed signs and less reliable left-hand detections.     In the sequence-length

comparison, the 64-frame Extra Trees representation scored higher than the 16- and

32-frame versions.

The best channel setting reached 41.9% grouped-CV accuracy and 0.405 macro-F1. Both

hands with coordinates alone reached 29.1%; adding angle information therefore helped in

this comparison. The right-hand-plus-angle setting reached 33.2%, while left-hand-plus-

angle reached 17.7%. This dierence should not be read as evidence that the left hand is

unimportant to sign language. It is consistent with the missingness measurements: the left

hand is missing more often in both video sources, and some WLASL signs are performed

primarily with one hand. A model that receives incomplete left-hand measurements has

fewer usable features for those clips.

The velocity ablation reached 38.2%, below the 41.9% obtained without velocity. Velocity

may encode useful motion, but nite dierences also magnify frame-to-frame landmark

jitter and missingness. With this feature construction and sample size, the extra dimen-

sions did not oset those eects. A dierent temporal model or a more robust motion

representation could behave dierently; that question is not answered by this one abla-

tion.

4.5 Error analysis
Validation scores hide large dierences between glosses.    Many classes have only a few

clips in the 294-clip validation set, and the Extra Trees model missed every validation


                                              15
example for some classes. Among the most frequent confusions, cousin was predicted

as hat and candy as pink. With so few examples per class, these patterns are useful

leads, but not rm conclusions.

This error review uses validation predictions, not the held-out test labels.   It reports

per-class support and recall because a single aggregate value cannot show whether errors

are spread evenly across the vocabulary.    If a class has one validation clip, a correct

prediction changes its recall from zero to one; estimates for these classes are therefore

coarse.   Confusion pairs also need context:    two glosses may share a hand location or

movement, but a few errors are not enough to conclude that their signs are intrinsically

similar. A larger signer-diverse sample and review of the original clips would be needed

to distinguish genuine visual similarity from missed or noisy landmarks.

The examples in the saved analysis include several small confusion pairs rather than one

dominant error pattern. This is consistent with a 100-class task in which many glosses

have limited support.   We use the plots and per-class les to guide inspection, not to

claim a complete linguistic account of why two signs are confused.

Chapter 5

Discussion

5.1 Main ndings
The comparison favoured Extra Trees and logistic regression among the classical models.

Using both hands and hand angles was more useful than coordinates alone, and adding

velocity did not help in the tested setup.     The 64-frame version also did better than

shorter sequences in the Extra Trees length comparison.

The gap between grouped-CV averages and nal test results needs careful interpretation.

The grouped folds use only the training partition and hold out signers within those 868

clips. The nal test estimator uses train plus validation, or 1,162 clips, before it predicts

the 304 test clips.   It therefore has more examples available for tting than any cross-

validation fold. At the same time, the test signers are a particular group of 15 people and

the number of clips per class is uneven. Both factors can contribute to a test score higher

than the CV average. We report the discrepancy rather than treating the test score as a

replacement for the grouped-CV estimate.

The best classical model's test macro-F1 (0.615) is close to its accuracy (0.618), and its

balanced accuracy is 0.646. For logistic regression, the corresponding test macro-F1 is

0.597 and balanced accuracy is 0.618. Across the weaker models, the dierence between

accuracy and macro-F1 is more visible, particularly for kNN. This reinforces the value of

looking at more than the fraction of correctly classied clips, while keeping in mind that

all these metrics are based on one nite test set.




5.2 Limitations
We could recover clips for 1,466 of the 2,038 metadata instances, and the missing 572 may

not be a random subset. There are few examples for many of the 100 glosses, and the data

are unevenly distributed across signers. Hand landmarks are often missing or unstable,

which removes useful information from the features.       We visually checked 20 overlays,




                                             17
but did not manually review every clip. Some frame ranges from YouTube sources may

include a few frames of a title card. Finally, the test partition represents only 15 signers,

so its score is one estimate and class-level results may change with a dierent group of

signers.

There are also limitations in the feature design.    Shoulder normalization helps reduce

changes in scale and translation, but it does not correct for all camera-angle or body-

proportion dierences. The two-bin representation deliberately compresses the sequence

and can lose brief movements or ne timing. Joint angles use selected triples rather than

a learned skeleton graph, and the simple velocity features can be noisy.      Our hyperpa-

rameter grids cover a limited set of options, so the winning models are best among the

congurations we tested, not necessarily among every possible conguration. Finally, the

random-clip diagnostic illustrates leakage but is not a substitute for repeated group-aware

evaluations.




5.3 Validity and leakage controls
No signer appears in more than one of the saved train, validation, and test partitions.

We selected the classical settings using grouped folds within the training set, and tted

data-dependent preprocessing on the relevant training partition. The random clip exper-

iment is reported separately because its signer overlap makes it unsuitable for the main

comparison. We used the test partition after model selection for the scores in this report;

it should not be used to choose further settings.

Conclusion

6.1 Conclusion
We assembled a usable landmark set from the available WLASL-100 videos and used it to

compare six classical classiers and two sequence models under a signer-independent split.

Extra Trees had the highest test accuracy at 61.8%; logistic regression followed at 60.5%.

The experiments also exposed practical limits of the data: many videos were unavailable,

hand detections were incomplete, and there are few clips per gloss. The nal test scores

are reported for comparison, but further model choices should be made without using

that test set.
